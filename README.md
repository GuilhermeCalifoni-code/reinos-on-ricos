# Reinos Oníricos — Companheiro de Jogo

Ferramenta digital para condução de sessões de **Reinos Oníricos RPG**.

O sistema foi pensado para apoiar Mestres e jogadores durante a mesa, priorizando agilidade, atmosfera e organização operacional — sem substituir o Livro Básico ou a documentação da campanha.

## Recursos

### Mestre

- Central de condução de cenas.
- Controle alternado de rodada: Desvelados → Mestre.
- Antagonistas, ações, passivas, reações e distância.
- Contadores de pressão e objetivos narrativos.
- Resolução de Testes Oníricos.
- Registro de acontecimentos da cena.
- Consulta rápida das fichas dos Desvelados.
- Ajuste de Vida e Ruptura.
- Diário operacional para anúncios e narração.
- Estúdio de Cenas:
  - múltiplas cenas por campanha;
  - mapa narrativo ou imagem local;
  - grid quadrada ou livre;
  - neblina de guerra;
  - revelação de áreas;
  - tokens de Desvelados e ameaças;
  - informações privadas do Mestre.

### Jogadores

- Ficha digital do Desvelado.
- Criação, duplicação, importação e exportação de fichas em JSON.
- Atributos, Domínios, Ancoragem, Vínculos, Recursos e Equipamentos.
- Controle de Vida, Foco, Proteção Onírica e Ruptura.
- Rolador de Testes Mundanos, Oníricos e Movimento de Morte.
- Guia dos Domínios e referência rápida de regras.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Supabase opcional para sincronização de personagens
